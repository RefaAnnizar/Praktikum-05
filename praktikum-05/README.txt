PRAKTIKUM 05 — BOX MODEL, FLEXBOX & POSITIONING

Struktur:
- p1-boxmodel/index.html
- p2-flexlab/index.html
- p3-positioning/index.html
- p4-dashboard/index.html
- p4-dashboard/css/style.css
- laporan.md

Cara menjalankan:
1. Ekstrak folder praktikum-05.
2. Buka folder di Visual Studio Code.
3. Jalankan setiap index.html dengan Live Server.
4. Ikuti eksperimen DevTools pada modul dan cocokkan hasilnya dengan laporan.md.
5. Lengkapi Nama, NIM, Kelas.
6. Ambil screenshot aktual dashboard pada viewport 1366 px dan 375 px,
   simpan sebagai p4-dashboard/desktop.png dan p4-dashboard/mobile.png.
7. Kumpulkan folder praktikum-05 dalam ZIP sesuai format NIM_Nama_P05.zip.

Catatan: tabel pengamatan laporan memuat hasil yang diharapkan dalam modul
sebagai acuan teoritis. Pengukuran aktual dan screenshot browser harus
dilakukan pada komputer pengguna.
